# اینترنت پرو — Internet Pro

اپلیکیشن اندروید برای روشن/خاموش کردن سرویس اینترنت اپراتور با کد دستوری `*10*327#`.

- روشن کردن: ارسال خودکار `1` در همان نشست USSD
- خاموش کردن: ارسال خودکار `2` در همان نشست USSD
- دکمهٔ گرد واحد: سبز = روشن، قرمز = خاموش
- انتخاب سیم‌کارت در گوشی‌های دو سیم‌کارته (پیش‌فرض: سیم‌کارت ۱)
- یک بنر استاندارد تپسل در پایین صفحه
- فارسی و راست‌به‌چپ؛ Android 8 تا 16 (minSdk 26، targetSdk 35)

## دانلود APK

**آخرین نسخه: 1.9** — [دانلود APK امضاشده](releases/InternetPro-1.9.apk) · [نسخهٔ latest](releases/InternetPro-latest.apk)

نسخه‌های قدیمی‌تر در پوشهٔ [`releases/`](releases/) موجودند. مقدارهای SHA-256 در [`releases/SHA256SUMS.txt`](releases/SHA256SUMS.txt) ثبت شده‌اند.

### نصب
1. APK را دانلود و باز کنید.
2. در صورت نیاز، نصب از این منبع را برای مرورگر/فایل‌منیجر مجاز کنید.
3. مجوز تماس را بدهید.
4. برای ارسال خودکار پاسخ USSD، در تنظیمات اپ «حالت پشتیبان» (دسترس‌پذیری) را فعال کنید.

## انتشار در کافه‌بازار

راهنمای فارسی، APK، آیکون و تصاویر بازار در [`bazaar/`](bazaar/) قرار دارد. ثبت حساب توسعه‌دهنده و ارسال نهایی در پیشخان باید توسط صاحب حساب انجام شود.


## ساخت نسخهٔ انتشار

پیش‌نیاز: JDK 17، Android SDK platform 35 و Android Gradle Plugin/Gradle از طریق wrapper.

برای ساخت Release باید مقدارهای زیر را در محیط تنظیم کنید؛ هیچ کلید تبلیغ یا کلید امضایی داخل مخزن قرار ندارد:

```bash
export TAPSELL_APP_KEY='کلید اپ تپسل'
export TAPSELL_ZONE_ID='شناسهٔ بنر استاندارد'
export INTERNETPRO_KEYSTORE='/مسیر/امن/keystore.jks'
export INTERNETPRO_STORE_PASSWORD='رمز keystore'
export INTERNETPRO_KEY_ALIAS='نام alias'
export INTERNETPRO_KEY_PASSWORD='رمز کلید'
cd source
./build.sh
```

فایل خروجی در `releases/InternetPro-latest.apk` قرار می‌گیرد. برای به‌روزرسانی، همان نام بسته و همان کلید امضا باید حفظ شود.

## حریم خصوصی و مجوزها

- گزارش عملیات و انتخاب سیم‌کارت روی دستگاه می‌مانند.
- SDK تبلیغات تپسل برای نمایش/سنجش تبلیغ ممکن است شناسه‌های تبلیغاتی، اطلاعات برنامه و دستگاه و IP را پردازش کند. جزئیات در [`bazaar/privacy.html`](bazaar/privacy.html) و سیاست حریم خصوصی تپسل آمده است.
- مجوز دسترس‌پذیری فقط برای تایپ پاسخ `1` یا `2` در پنجرهٔ USSD استفاده می‌شود.
- `AD_ID` به SDK تبلیغاتی مربوط است، نه به فرایند انتشار در یک فروشگاه خاص؛ حذف آن ممکن است روی تبلیغات تپسل اثر بگذارد.

## نکته‌های فنی

- پاسخ دوم USSD داخل همان نشست ارسال می‌شود تا از خطای `invalid code` جلوگیری شود.
- بنر تپسل فقط پس از دریافت تبلیغ نمایش داده می‌شود؛ اگر شبکه پاسخ تبلیغ ندهد، جایگاه مخفی می‌ماند.
- کلید امضا (`keystore.jks`) عمداً در مخزن نیست. آن را محرمانه و پشتیبان‌گیری‌شده نگه دارید.
