حریم خصوصی — اینترنت پرو (Internet Pro)

آخرین به‌روزرسانی: ۲۴ نوامبر ۲۰۲۶

این برنامه چه کار می‌کند؟

اینترنت پرو سرویس اینترنت اپراتور شما را با کد دستوری *10*327# مدیریت می‌کند. با لمس دکمهٔ اصلی، برنامه کد را ارسال می‌کند و در همان پنجرهٔ USSD عدد ۱ (روشن) یا ۲ (خاموش) را به‌صورت خودکار می‌فرستد.

تبلیغات و داده‌های مربوط به آن

این برنامه برای نمایش یک بنر تبلیغاتی از SDK شبکهٔ تبلیغاتی تپسل استفاده می‌کند. هنگام درخواست یا نمایش تبلیغ، تپسل ممکن است برخی اطلاعات دستگاه و برنامه را پردازش یا با شرکای تبلیغاتی خود به‌اشتراک بگذارد؛ از جمله شناسهٔ تبلیغاتی اندروید، شناسه‌های دستگاه/برنامه، نام و نسخهٔ برنامه، مدل و نسخهٔ سیستم‌عامل، زبان و مشخصات نمایشگر، نشانی IP و اطلاعات تقریبی شبکه. تپسل این داده‌ها را برای ارائه، شخصی‌سازی و سنجش تبلیغات و پیشگیری از تقلب به‌کار می‌گیرد. جزئیات و سیاست تپسل را در سیاست حریم خصوصی تپسل بخوانید.

  • برنامه برای انتخاب سیم‌کارت، اطلاعات سیم‌کارت را روی خود گوشی می‌خواند. SDK تبلیغات ممکن است با اجازهٔ تلفنِ برنامه، نوع شبکه را نیز تشخیص دهد.
  • برنامه مجوز مکان نمی‌گیرد؛ با این حال IP ممکن است برای تخمین مکان کلی شبکه استفاده شود.
  • گزارش عملیات و انتخاب سیم‌کارت در خود گوشی می‌مانند و برای تبلیغات به تپسل ارسال نمی‌شوند.
  • مجوز اینترنت در نسخهٔ تبلیغ‌دار فقط برای درخواست و نمایش تبلیغ استفاده می‌شود.
  • در مناطق مشمول قوانین رضایت، تنظیم نمایش تبلیغات شخصی‌سازی‌شده تابع انتخاب کاربر و سازوکار رضایت SDK است.

چرا این دسترسی‌ها لازم است؟

  • INTERNET / ACCESS_NETWORK_STATE / AD_ID: برای درخواست و نمایش بنر تبلیغاتی تپسل و شناسهٔ تبلیغاتی مربوط به آن.
  • CALL_PHONE: برای ارسال کد دستوری USSD از طریق API رسمی اندروید.
  • READ_PHONE_STATE / READ_PHONE_NUMBERS: برای تشخیص سیم‌کارت‌های فعال و ارسال کد از سیم‌کارت انتخابی شما (در گوشی‌های دو سیم‌کارته).
  • POST_NOTIFICATIONS: برای نمایش آیکون وضعیت «پرو» در نوار وضعیت هنگام فعال بودن سرویس.
  • دسترس‌پذیری (Accessibility): فقط برای تایپ کردن عدد ۱ یا ۲ داخل پنجرهٔ USSD اپراتور، در همان نشستی که خودتان باز کرده‌اید. هیچ محتوای دیگری از صفحه خوانده، ذخیره یا ارسال نمی‌شود.

Privacy Policy — Internet Pro

Last updated: November 24, 2026

What does this app do?

Internet Pro manages your carrier's internet service using the USSD code *10*327#. When you tap the main button, the app sends the code and automatically replies with 1 (on) or 2 (off) inside the same USSD session.

Advertising and related data

This app uses the Tapsell advertising SDK to display a banner. When an ad is requested or displayed, Tapsell may process or share certain app and device information with advertising partners, including the Android Advertising ID, device/app identifiers, app name and version, device model and operating-system version, language and screen details, IP address, and general network information. Tapsell uses this information to deliver, personalize, measure, and protect advertising. See the Tapsell Privacy Policy for details.

  • SIM information is read locally to select the SIM used for USSD. With the app's phone permission, the advertising SDK may also infer network type.
  • The app does not request location permission; an approximate general location may nevertheless be inferred from the IP address.
  • The operation log and SIM selection remain on the device and are not sent to Tapsell for advertising.
  • Internet access in the ad-supported version is used to request and display ads.
  • In regions where consent is required, personalized advertising is subject to the user's choice and the SDK's consent flow.

Why are these permissions needed?

  • INTERNET / ACCESS_NETWORK_STATE / AD_ID: to request and display Tapsell banner ads and use the related advertising identifier.
  • CALL_PHONE: to send the USSD code via the official Android API.
  • READ_PHONE_STATE / READ_PHONE_NUMBERS: to detect active SIMs and send the code from your selected SIM (dual-SIM phones).
  • POST_NOTIFICATIONS: to show the "Pro" status icon in the status bar while the service is active.
  • Accessibility: solely to type the digit 1 or 2 into the carrier's USSD dialog, within the same session you opened. No other screen content is read, stored, or transmitted.
